# 🔐 Random Password Generator

## 📌 About The Project

Random Password Generator is a simple and useful web application that allows users to generate random and strong passwords quickly.

The project was developed to practice **JavaScript logic, DOM manipulation, user interaction, and dynamic content generation**. It provides a simple interface where users can generate passwords according to their needs.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ✨ Key Features

### 🔑 Password Generation

* Generate random passwords instantly.
* Create different password combinations.
* Generate strong and unpredictable passwords.

### ⚙️ Easy to Use

* Simple and clean interface.
* Easy password generation process.
* User-friendly design.

### 📋 Copy Password

* Easily copy the generated password.
* Quickly use the password for different purposes.

### 📱 Responsive Design

* Works on desktop and mobile devices.
* Simple responsive layout.

## 🚀 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Open the project folder and run the `index.html` file in your browser.
